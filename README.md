<h1 align="center">KeyShelf для Android</h1>

[English](README.en.md) · [Скачать APK](https://github.com/Frommer-droid/KeyShelf-Android/releases/latest) · [Windows-версия](https://github.com/Frommer-droid/KeyShelf)

Локальное хранилище аккаунтов, API-ключей и произвольных данных в зашифрованном KDBX4. Версия 0.2.0. Android 8.0+; проверено на Redmi Note 10 Pro с Android 13. Приложение распространяется APK, без Google Play.

## Установка

Скачайте APK со страницы релиза и разрешите установку из выбранного источника. Создайте хранилище или свяжите телефон с Windows-версией через Настройки → С компьютером → Сканировать QR. Компьютер и телефон должны быть в одной локальной Wi-Fi сети. При конфликте данные не перезаписываются автоматически.

## Быстрый доступ

В настройках разрешите службу специальных возможностей «Плавающая кнопка». При фокусе текстового поля другого приложения появится иконка KeyShelf. Нажмите её, найдите запись по названию или метке, раскройте и нажмите значение для вставки. Кнопка редактирования меняет отдельное поле. Поиск и раскрытая запись сохраняются до блокировки или завершения процесса. Иконку можно перетаскивать; её положение запоминается на устройстве.

На Xiaomi для фоновой работы включите системный автозапуск и режим батареи «Без ограничений». После загрузки и разблокировки телефона главное окно не открывается автоматически. Принудительная остановка в системных настройках отключает фоновую работу до следующего ручного запуска. Вставка зависит от поддержки текстового поля другим приложением.

## Хранилище

«Название» показывается в заголовке, необязательная «Метка» используется для поиска. Тип записи определяет поля. Избранное, фильтры и сброс поиска доступны в основном окне. Настройка «Использовать мастер-пароль» общая для устройства и независима от Windows: при отключении ключ защищён AndroidKeyStore, последнее хранилище открывается автоматически. Неизвестный файл требует пароль один раз. База остаётся зашифрованной; пароль и ключ автооткрытия не синхронизируются.

Храните отдельные зашифрованные резервные копии. Мастер-пароль восстановить нельзя. Удаление приложения удаляет его локальное хранилище и ключи. Служба специальных возможностей используется для определения сфокусированного поля и вставки выбранного значения; облачного сервера нет.

## Разработка

Нативный Kotlin, JDK 17, Android Platform 35, target API 33. [Сборка и проверки](DEVELOPER.md), [установка и разрешения](Установка.md). Portable сборка: `tools/build-portable.ps1` с параметрами `-Jdk`, `-AndroidJar`, `-Aapt2`, `-Zipalign`, `-Gradle`; она выполняет тесты и создаёт подписанный APK в outputs. Личный signing key не входит в репозиторий; самостоятельная сборка создаёт новую identity и не может обновить опубликованный APK без удаления прежней установки.

## Ручной обмен изменениями

Локальные правки сохраняются на устройстве, но передаются другому устройству только по кнопке «Сохранить» (на Android — дискета). Получатель выбирает «Принять» или «Отклонить». При отказе отправитель восстанавливается из версии получателя, если после отправки не было новых правок. Автоматической отправки каждые 30 секунд нет. Нужны обе версии: Windows 0.5.0 и Android 0.2.0.
