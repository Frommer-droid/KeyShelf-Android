# История изменений (Release Notes)

## Версия 0.2.0 (2026-10-12)

*Ручной обмен базой с подтверждением и удобная работа с большими списками.*

### ✨ Новые возможности

- Изменения отправляются одним пакетом только по «Сохранить»; автоматическая отправка каждые 30 секунд отключена.
- «Принять» делает базу получателя копией отправленной версии; «Отклонить» восстанавливает отправителя из базы получателя.
- Синяя квадратная кнопка с дискетой для отправки накопленных изменений.
- Имя открытой базы, алфавитные сервисы и удобный поиск сервиса в редакторе.

### 🐛 Исправления ошибок

- После удаления выделяется соседняя видимая запись, прокрутка сохраняется.
- После обновления списка сохраняются поиск и положение; улучшены свайпы длинных редакторов и открытие клавиатуры.
- Сервис и тип первыми в редакторе, дополнительные поля вставляются под выбранным полем.

### 🛡️ Обмен и совместимость

- Протокол 3: подтверждения, неизменяемые отправленные пакеты и защита последующих локальных изменений.
- Обновляйте обе версии вместе: KeyShelf Windows 0.5.0 и Android 0.2.0. Формат KDBX4 сохранён.

## Версия 0.1.1 (2026-10-10)

*Перемещаемая плавающая иконка, стабильный поиск при синхронизации и единое оформление экранов.*

### ✨ Новые возможности

- Плавающую иконку можно перетаскивать; положение сохраняется на устройстве и ограничено экраном.

### 🐛 Исправления ошибок

- Проверка синхронизации без изменений не пересоздаёт поиск и список; при обновлении базы сохраняются запрос, фокус и прокрутка.
- Подсказка Android Autofill не конкурирует с работающей плавающей службой.
- Сохранённое сопряжение отделено от результата обмена; ошибка соединения не дублируется и сохраняется до следующего успешного обмена.
- Значения типа «Другое» показываются без технических подписей «Поле 1»; повтор названия сервиса в заметке скрыт только при просмотре.
- После обновления APK подключение плавающей службы восстанавливается с увеличенной задержкой для MIUI.

### 🎨 Интерфейс

- Обновлены синхронизация, поля редакторов, кнопки и сканер QR.
- Мини-поиск получил один синий контур 1 dp, компактное сообщение пустого поиска и разделитель перед результатами.
- Надписи на страницах настроек и синхронизации выровнены по центру.

### ✅ Проверки

- 41 проверка интерфейса и жизненного цикла на синтетических данных; сценарии обмена, ошибок, перетаскивания и блокировки.
- Формат KDBX и протокол локального обмена совместимы с KeyShelf для Windows 0.4.0.

## Версия 0.1.0 (2026-10-10)

*Первый Android-компаньон KeyShelf с быстрым поиском и синхронизацией по локальной Wi-Fi сети.*

### ✨ Новые возможности

- Локальное зашифрованное хранилище KDBX4: аккаунты, API-ключи и произвольные данные.
- Плавающая иконка при фокусе текстового поля, поиск, избранное и вставка нажатием значения.
- Редактирование отдельных значений в мини-режиме; сохранение раскрытой записи после вставки.
- Сопряжение с Windows по QR, защищённая LAN-синхронизация с обнаружением конфликтов.
- Настройка запроса мастер-пароля и автоматическое открытие через AndroidKeyStore.

### 🎨 Интерфейс

- Тёмная тема, акценты типов, единые диалоги, закреплённые фильтры и прокручиваемый список.
- Раздельные «Название» и поисковая «Метка», динамические поля по типу записи.

### 🐛 Исправления ошибок

- Удалённые поля не возвращаются; «Другое» показывает обычные значения без маски и чужих подписей.
- Мини-аккордеон раскрывается и сохраняет состояние; служба восстанавливает подключение после обновления.

### ✅ Проверки

- 35 проверок интерфейса и жизненного цикла на синтетических данных, 6 проверок KDBX-совместимости.
- Работа и запуск после перезагрузки проверены на Redmi Note 10 Pro с Android 13.
